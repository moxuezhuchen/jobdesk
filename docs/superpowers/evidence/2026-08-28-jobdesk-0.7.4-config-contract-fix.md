# JobDesk 0.7.4 configuration-contract fix-forward evidence

## Boundary

This candidate changes only the JobDesk consumer.  ConfFlow `v2.1.6`, the
configured production endpoint, `/opt/ConfFlow`, rollback environments, tags,
and published releases are unchanged.  Merge, tag, release, workload, and
production promotion remain separate authorization gates.

## Trigger

The formally released ConfFlow `v2.1.6` CLI emits
`confflow.configuration-contract.v1` and
`confflow.configuration-validation.v1`.  JobDesk `v0.7.3` instead parsed an
unpublished consumer-invented response shape, so released side-by-side
validation failed closed before workload upload.

## Fix-forward contract

- Exact top-level and producer/issue fields are required; duplicate and unknown
  fields fail closed.
- The workflow schema SHA-256 uses the producer canonical JSON rule: UTF-8,
  sorted keys, compact separators, `ensure_ascii=False`, no final newline, and
  non-finite numbers rejected.
- Producer package/version/commit/dirty and executable identity are bound to
  verified capability provenance.
- Validation schema/hash, boolean status, issue shape, and exit status `0/1`
  must agree.
- The checked-in fallback remains restricted to the exact approved ConfFlow
  `2.0.0` identity and only an explicitly unsupported command.  A malformed
  response from a command-capable producer never selects the fallback.

## Verification gates

The compatibility workflows retain the five producer control-schema snapshot
checks and add an independent installed-runtime gate.  That gate runs the
installed CLI's capabilities, contract, valid-validation, and
invalid-validation commands, then feeds their actual stdout, stdin bytes, and
exit codes through the JobDesk runtime parser and SSH client.

Local acceptance used the previously downloaded formal ConfFlow `v2.1.6`
environment at `/tmp/confflow-v2.1.6-production-verify`; it returned workflow
schema SHA-256
`38c45669ff9f3be0d352ab8d6bb2a64be9cd67bb2327dd89cd72d804aee2e7ca`,
valid exit `0`, invalid exit `1`, and one structured invalid issue.  This is a
non-computing contract check, not production promotion or workload evidence.
